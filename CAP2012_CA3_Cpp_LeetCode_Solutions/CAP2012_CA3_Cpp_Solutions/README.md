# CAP2012 CA3 — C++ LeetCode Solutions

Sixteen solutions, organized using the assignment's Easy / Medium / Hard folders and exact filenames.

Upload these folders and this README to a public repository named `CAP2012_CA3_LeetCode_<RegistrationNumber>`.

Each `.cpp` file is a LeetCode class solution (not a standalone program). Submit it to the matching LeetCode C++ editor. Linked-list problems use LeetCode's provided `ListNode` definition. `bits/stdc++.h` is supported by LeetCode's GNU C++ compiler.

Review and test every solution yourself, including edge cases, and be ready to explain the approach and complexity in the viva.
